# warm-handoff

Working repo for a weekend research-and-prototype project: a problem statement, deck and proof of concept for a product role. Not an application.

Start with `BRIEF.md` (goal, timebox, restrictions) and `CLAUDE.md` (layout and conventions). Decisions are in `docs/decisions/`; open assumptions to verify are in `docs/verify.md`.

`research/sources/` holds third-party material and is gitignored.
