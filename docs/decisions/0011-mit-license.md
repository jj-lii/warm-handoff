# 0011 License: MIT for our own code and docs
Status: accepted
Date: 2026-10-04
Context: The POC will be deployed publicly and the repo may be shared with reviewers; without a license, nobody else may legally reuse it.
Decision: MIT, copyright the author. It covers what we wrote. It does not cover `research/sources/` (ExaCare's copyrighted material, gitignored) or third-party libraries (their own licenses). Medicare manual excerpts are US government works.
Alternatives: No license (all rights reserved; fine for a private repo, unclear for a shared one); Apache-2.0 (adds a patent grant this project doesn't need).
Consequences: Anyone may reuse the code. Short quotes from ExaCare material in docs stay attributed and are not relicensed by MIT.
