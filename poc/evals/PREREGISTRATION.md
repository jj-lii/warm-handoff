# Pre-registration: holdout evaluation

Written 2026-10-04, before any engine has run on the holdout. Code as of commit `4c3131c`. Design: ADR 0015 and ADR 0016. All letters are synthetic.

The holdout runs once: `npm run eval -- holdout --final`. The runner refuses unless this file is committed unchanged and contains the hash of every file listed below; it then writes `private/holdout-final-run.json`, so it can't run twice. Every number it produces is reported, including any that go against Jev.

## Data

- Holdout: 40 synthetic denial letters generated by Gemini 3.8 Flash from the same 40-recipe mix as dev and golden, labelled blind by the author. Claude has not read the letters or the labels; only row and id counts were checked (40 letters, 40 labelled).
- Labels are frozen as of the hash below. No adjudication or relabelling of the holdout, before or after the run.
- Gold for each letter: the author's latest label. Its correct next step is `verdictOf(labels)` in `lib/check.ts` (rules conflict, then clinical dispute, then missing documents; no reason means a person reads it).

## Engines

| Engine | Model | Notes |
|---|---|---|
| keyword | frozen regex in `lib/rules.ts` | the floor |
| haiku | `claude-haiku-4-5`, temperature 0 | same six questions, structured output |
| gemini | `gemini-3.1-flash-lite`, temperature 0, thinking off | same prompt as Haiku; Gemini also wrote the letters |
| jev | `jev-latest` (TypeSafe alias) | the model version returned is recorded in the results |

No answer cache on the holdout: every engine is called fresh.

## Metrics (definitions in `evals/metrics.ts`)

Decision threshold 0.5. Review band 0.3 to 0.7.

- **Primary: right next step.** Share of letters where the engine's next step equals the gold next step (4 classes), with a 95% Wilson interval.
- **Primary test: Jev against the keyword baseline** on right next step, exact two-sided McNemar on paired letters, alpha 0.05.
- Secondary, reported for every engine: precision at the top of the queue (top 10 by highest rules-conflict probability, ties averaged); contestable denials caught; wrongly contested; sent to a person (no reason detected, or any probability inside the review band for model engines); reason set matches labels; per-reason precision and recall with Wilson intervals; Brier score; hard-case slice (letters written with a distractor or an out-of-scope reason); latency p50/p90; tokens and USD per letter.
- Jev against Haiku and against Gemini: same McNemar test, reported. A non-significant result means no difference was detected at n = 40; it does not show the engines are equivalent.
- Engine errors are reported per engine; a letter an engine fails on is excluded from that engine's metrics only.

## Predictions, stated before the run

Based on dev and golden:

1. Jev beats the keyword baseline on right next step (McNemar p < 0.05). On golden: Jev 90%, keyword 70%, p = 0.021.
2. No significant difference between Jev and Haiku, or between Jev and Gemini (all three were at 90% on golden).
3. Jev sends the largest share of letters to a person, roughly 40 to 55% (48% on golden), because many of its probabilities fall inside the review band. Haiku and Gemini send roughly 10 to 20%.
4. **Known weakness, stated in advance:** letters saying the member's care "can be provided by custodial or non-licensed staff" are ambiguous between "the care isn't skilled" (contest on the facts) and "the care she already gets will do" (contest on the rules). Expect wrong next steps on some of these letters. They count as misses in every headline number; any analysis of them is reported separately and labelled post hoc.

If prediction 1 fails, the report says Jev did not beat a keyword baseline on this test.

## Disclosures

- Synthetic letters only. Results say nothing about real-world prevalence or appeal outcomes (V23).
- One labeller (the author). Residency labels are known to be inconsistent (`BRIEF.md`), so residency precision and recall are unreliable.
- Claude wrote the six questions and tuned two of them on dev; Claude proposed the golden adjudication (v2, accepted by the author, no next step changed). Haiku is also a Claude model.
- Gemini wrote every letter and is also an engine, so it may be advantaged.
- On dev, the author relabelled 7 letters after the engines disagreed with them (therapy participation).
- Golden has been seen, so it is no longer a clean test. A custodial-question change written after seeing golden misses was stashed and is not used.
- n = 40: the test has low power, and the intervals are wide.
- The real slice (about 20 public Council passages) is not part of this run. It will be labelled blind and run with the same frozen code, and reported separately as exploratory.
